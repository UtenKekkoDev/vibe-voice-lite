## 用语音切换模式

按住右 Ctrl，单独说“第一”“第二”或“第三”，对应语音听写、开发指令和需求问答。也可以说“Switch mode”先听选项，再回答模式名或编号。开启 Serena 后会播报切换结果。

## 需求问答

- 说“OK，就这样”或“停止”可结束访谈。AI 会分别列出已确定和待定事项，成功后 Serena 播报简短回执。
- 说“直接输入”会输出最近一段自己的识别原文。说“明天下午三点开会，这句直接输入”只会输出同一句的正文。直出遵循自动粘贴开关，完成后仍处于需求问答模式。
- 程序能读取用 Markdown 包裹的 JSON 和省略空正文的追问。失败时，卡片显示具体原因，本地日志保留诊断信息。

## 设备与投递

Serena 在下次播报前检查 Windows 默认输出设备。识别期间关闭自动粘贴会阻止本轮投递。更换 Qwen-ASR 服务器或端口时，程序会清除旧密钥。
