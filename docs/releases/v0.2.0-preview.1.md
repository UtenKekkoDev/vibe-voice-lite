## Windows x64 预览版

下载下方的 `vibe-voice-lite-windows-x64.zip`，解压整个目录，双击 `vibe-voice-lite.exe`。首次启动会显示设备与服务状态。普通口述需要一个可用的识别模型或已配置的在线识别服务。模型、API Key、Python 和 CUDA 需另行配置。

- 托盘里的「复制上次结果」可取回最近一次完整口述或访谈总结。退出程序后清除。
- 访谈时说「这个先待定」可以搁置当前问题。看到可以整理的提示后，仍可继续补充。单独说「先整理到这里」才生成最终总结。
- 设置中可查看最近口述的识别、AI 与语音播报耗时。计时记录只含阶段和耗时。
- 首次启动与托盘设置均可检查麦克风、识别、AI 和 TTS。远程 AI 配置在实际调用时验证。

识别模型与本地播报的安装步骤见压缩包内的 README 和 docs 目录。可用 PowerShell 的 `Get-FileHash -Algorithm SHA256` 对照同一页的校验文件核验下载。
